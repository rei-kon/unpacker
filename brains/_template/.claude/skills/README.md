# .claude/skills/ — скиллы агента

Скилл — папка с файлом `SKILL.md`, в котором описан повторяемый навык («как мы делаем КП»,
«как разбираем созвон»). Движок передаёт эти скиллы агенту вместе с мозгом.

```
.claude/skills/
└── moy-navyk/
    └── SKILL.md
```

Минимальный `SKILL.md`:

```markdown
---
name: moy-navyk
description: Когда звать этот навык — одной фразой.
---

# Мой навык

Шаги, которые агент должен пройти. Пиши по делу, как инструкцию сотруднику.
```

Начинать со скиллов не обязательно: сперва хорошо опиши агента в `CLAUDE.md`. Скиллы нужны,
когда одна и та же задача повторяется и её порядок хочется зафиксировать.

Файл можно удалить — папка нужна, README нет.
