# knowledge/ — знания агента

Сюда кладут материалы, на которые агент опирается: инструкции, шаблоны документов, факты
о продукте, примеры хороших ответов. Формат — обычный markdown, никакой особой разметки.

Правила простые:

- один файл — одна тема, имя файла говорит о содержимом (`tarify.md`, `shablon-kp.md`);
- в `CLAUDE.md` перечисли, что читать перед работой, — иначе агент может не заглянуть сюда;
- сюда не кладут секреты (токены, пароли, ключи) и персональные данные клиентов: содержимое
  папки уходит в контекст модели.

Файл можно удалить — папка нужна, README нет.
