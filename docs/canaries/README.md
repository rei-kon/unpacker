# Канарейки — зафиксированное поведение SDK

Здесь лежат **факты**, а не ожидания. Каждый файл — результат прогона `make canary` на
Linux-VPS с живым `claude` CLI и токеном подписки.

## Зачем это существует

План «Распаковщика» опирается на допущения о Claude Agent SDK: скиллы мозга видны на Linux,
resume не теряет историю, долгий MCP-вызов не рвёт поток, `interrupt()` не убивает клиента.
Каждое допущение — риск из §13. Канарейка проверяет допущение **до** того, как на нём построят
подсистему, а не после.

Цена ошибки несимметрична: узнать сейчас — день, узнать в Фазе 1a — неделя переделки.

## Правило

**Красная канарейка не чинится.** Она означает, что ложно допущение плана, а не код канарейки.
Порядок действий: зафиксировать факт здесь → починить план → и только потом трогать код.
Подгонять ассерт под реальность — значит терять единственный сигнал, ради которого всё затевалось.

## Что чем проверяется

| Канарейка | Допущение | Раздел плана / риск |
|---|---|---|
| C1 | скиллы мозга видны на Linux при `setting_sources=["user","project"]` | §4, риск #268 |
| C2a | resume с тем же cwd продолжает историю (**опора**) | §5.2 |
| C2b | что делает resume с чужим cwd (**разведка**) | риск #555 |
| C3 | долгий MCP-вызов >90с не рвёт поток на пине 0.2.121 | риск #676/#730 |
| C4a | `total_cost_usd` и `model_usage` читаются (**опора**) | §5.5 |
| C4b | включает ли `model_usage` субагентов, в отличие от `usage` (**разведка**) | §5.5 |
| C5 | работает ли `/compact` слэш-строкой (**разведка**) | открытый вопрос №1 |
| C6 | `get_context_usage()` отвечает на живой сессии | §5.5, слой 2 |
| C7 | `interrupt()` рвёт стрим и не убивает клиента | §5.1 |
| C8 | виден ли `message_thread_id` в личке (**проба, руками**) | §5.2, биндинги |

«Опора» — жёсткий ассерт, на этом стоит подсистема. «Разведка» — только запись факта:
у нас нет ожидания, которое можно опровергнуть, есть вопрос, требующий ответа.

## Формат записи

Файл на прогон: `<ГГГГ-ММ-ДД>-results.md`. Таблица: канарейка · допущение · **факт** ·
вердикт · что это меняет в плане. Версии `claude-agent-sdk` и `claude` CLI — обязательно:
без них факт не воспроизводим и через месяц бесполезен.
