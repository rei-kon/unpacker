# Распаковщик

Движок агентов на Claude Agent SDK. Берёт папку с описанием агента — «папку-мозг» — и делает
из неё живого агента в Telegram: с памятью диалога, кнопками, приёмом файлов и перезапуском
без потери контекста.

Дальше агентами управляешь словами. Первый агент, которого ставит установщик, — **Распаковщик**:
ему пишешь в Telegram «разверни вот этот мозг в телеграм», и он разворачивает следующего.
Никаких ssh и команд на каждого нового бота.

---

## Что это и зачем

Одна и та же оболочка — разные агенты. Оболочка (движок) у всех одинаковая, а агент — это
папка с файлом `CLAUDE.md`, где по-человечески написано, кто он и что делает. Хочешь второго
агента — делаешь вторую папку, а не второй сервер.

Что уже работает:

- Telegram-бот из папки-мозга: живой диалог, ответ «печатается» на глазах, длинные ответы
  режутся аккуратно;
- переключение агентов и проектов внутри одного бота (по топикам);
- **кнопки под ответами** из `buttons.yaml` — нажатие отправляет готовый промпт;
- **приём файлов** (документ, фото) и отдача файлов от агента;
- перезапуск сервера не теряет диалог — разговор продолжается с того же места;
- у бота протух доступ — владельцу приходит уведомление в Telegram, а не тишина;
- установка одной командой, обновление по релизам с откатом.

Чего ещё нет (честно):

| Что | Когда |
|---|---|
| Голосовые сообщения, расписания («сам пишет утром»), показ расхода по лимиту | Фаза 2 |
| **Веб-чат на сайте** (тот же агент в браузере) | **Фаза 3** |
| Агент для внешних клиентов на API-ключе, с лимитами | Фаза 4 |

Расход по подписке движок не считает — ни командой в боте, ни через Распаковщика. Спросишь
«сколько потратили» — получишь честное «пока не умею», а не выдуманные цифры.

## Сколько это стоит

Стоимость владения — порядок цифр в месяц, чтобы не было сюрпризов:

| Статья | Сколько | Комментарий |
|---|---|---|
| VPS | ~5–15 $ | Ubuntu 22+/24, **4 ГБ RAM** — рекомендуемый минимум |
| Подписка Claude Pro/Max | по тарифу Anthropic | одна подписка на всех твоих агентов |
| Сверх этого | 0 | движок за себя не берёт ничего |

Важное про **лимит подписки**: каждый ответ агента расходует тот же лимит Claude, что и твоя
работа в Claude Code. Бот, который бодро отвечает весь день, съедает лимит так же, как ты сам.
Лимит закончился — агент честно скажет об этом и будет ждать восстановления окна.

Отдельно и жёстко: **обслуживать внешних клиентов с подписки нельзя** — это нарушение правил
Anthropic, и оно энфорсится (сторонние обёртки отрезали от подписок). Подписка = ты и твои
сотрудники. Внешние клиенты — только на API-ключе; это Фаза 4, и такую поверхность движок
сейчас намеренно не поднимает.

## Шаг −1: пре-флайт (15 минут, руками)

Три вещи, которые скрипт сделать не может. Без них установка бессмысленна.

**1. Подписка Claude Pro или Max.** Оплачена, и ты можешь войти в неё в браузере.

**2. Бот в Telegram.** Напиши [@BotFather](https://t.me/BotFather):

- `/newbot` → имя → username (обязательно заканчивается на `bot`);
- скопируй **токен** — строка вида `123456789:AAE...`. Это пароль от бота: не публикуй его и
  не пересылай в чаты. Утёк — `/revoke` у BotFather и получи новый;
- включи топики в личке (нужно для «один бот — несколько агентов»):
  `/mybots` → твой бот → *Bot Settings* → **Topics in private chats** → *Enable*;
- узнай свой числовой id: напиши [@userinfobot](https://t.me/userinfobot), он пришлёт число.
  Только перечисленные id смогут писать боту, остальные получат отказ.

**3. VPS с Ubuntu 22.04+ или 24.04.** 4 ГБ RAM (в 2 ГБ движок не поднимет ни одного агента —
установщик такой сервер честно отвергнет), 20+ ГБ диска. Нужен вход по ssh:

```bash
ssh root@IP-адрес-сервера
```

*Windows:* `ssh` есть в PowerShell по умолчанию — `ssh root@IP`. Если нет, поставь
[Windows Terminal](https://aka.ms/terminal) или PuTTY. Все команды ниже набираются в терминале
**сервера**, а не своего компьютера.

Папка-мозг **не обязана быть git-репозиторием** — обычной папки на сервере достаточно.

## Быстрый старт: одна команда и четыре ответа

На сервере:

```bash
git clone https://github.com/rusanovproject-dotcom/unpacker.git /opt/unpacker
bash /opt/unpacker/install.sh
```

Репозиторий приватный (доступ — по зачислению на курс), поэтому GitHub попросит войти:
установщик покажет короткий код, который вводится в браузере на твоём компьютере. Путь для
продвинутых — fine-grained PAT с правом *Contents: Read* и клон вида
`https://<логин>:<PAT>@github.com/...`.

Посмотреть, что будет сделано, ничего не меняя:

```bash
bash /opt/unpacker/install.sh --dry-run
```

Что делает установщик по шагам: базовая защита сервера (файрвол только на ssh, автообновления
безопасности, вход по ключу вместо пароля — от каждого пункта можно отказаться флагом) →
проверки железа и инструментов, включая расчёт, сколько агентов уместится в твою RAM → Claude
Code CLI → код движка → **четыре вопроса** → разворачивает Распаковщика.

Четыре вопроса:

1. токен бота (ввод не отображается на экране — так и должно быть);
2. твой Telegram id — кому можно писать боту;
3. где держать папки-мозги;
4. чем платим за работу агента: подписка или API-ключ.

Финал — «открой бота и напиши `/start`». Плюс одна разовая операция: выдать боту долгоживущий
токен подписки, иначе доступ протухнет через час. Установщик печатает точные шаги
(`claude setup-token` покажет ссылку → открываешь её в браузере на своём компьютере →
копируешь короткий код → вставляешь обратно в терминал → получаешь строку `sk-ant-oat01-…`).

**Повторный запуск `install.sh` безопасен.** Это обновление, а не установка заново: он не
переспрашивает то, что уже знает, и не перезатирает твои настройки.

Не прошла проверка — установщик печатает не «ошибку», а список дел: что сделать и какой
командой. Починил → запусти снова, продолжит с того же места.

## Папка-мозг: из чего состоит агент

```
мой-агент/
├── CLAUDE.md          ← ОБЯЗАТЕЛЬНО: кто он, что делает, как отвечает
├── .brain.yaml        ← опционально: имя, модель, шаблон кнопок
├── knowledge/         ← опционально: знания (шаблоны, факты, инструкции)
└── .claude/skills/    ← опционально: навыки (SKILL.md)
```

Минимальный агент — один `CLAUDE.md`. Остальное добавляется по мере надобности.

Начинай с шаблона, там каждая строка прокомментирована:

```bash
cp -r /opt/unpacker/brains/_template ~/brains/мой-агент
nano ~/brains/мой-агент/CLAUDE.md
```

Готовый рабочий пример, который разворачивается без единой правки, — `examples/assistant/`.

Важное правило: **агент не пишет внутрь своей папки-мозга.** Память, присланные файлы и базы
живут в каталоге агента `~/agents/<имя>/state/`. Поэтому папку-мозг можно спокойно обновлять
через git: обновление не спотыкается о файлы, которые агент себе насоздавал.

---

## Как добавить агента

Скажи Распаковщику в Telegram:

```
разверни мозг ~/brains/мой-агент в телеграм
```

Он спросит недостающее (имя, токен нового бота), покажет план и после твоего «да» развернёт.
Каждому агенту нужен **свой** бот из BotFather: один токен = один бот.

Ему же можно писать «почему бот молчит?», «обнови движок», «добавь кнопку», «покажи ботов».
Чего он пока не умеет (например показать расход) — скажет прямо, а не придумает ответ.

## Команды и кнопки

| Команда | Что делает |
|---|---|
| `/start` | начать |
| `/help` | короткая справка — тот же список, что здесь |
| `/projects` | показать список агентов-проектов (только список) |
| `/switch` | `/switch <slug>` — переключиться на другого агента, новая сессия |
| `/status` | какой агент, какая сессия, какая модель, verbose, аптайм |
| `/stop` | прервать текущий ответ |
| `/close` | закрыть сессию окна |
| `/clear` | новый диалог без истории |
| `/model` | `/model opus\|sonnet\|haiku` — сменить модель |
| `/verbose` | `/verbose 0` тихо, `/verbose 1` — показывать шаги работы |

Кнопки под ответами берутся из `buttons.yaml` в каталоге агента (при первом деплое он
копируется из `.brain.yaml` мозга). Новая кнопка — две строки: `label` (что написано на кнопке)
и `prompt` (что уйдёт агенту). Твои правки в `buttons.yaml` обновление мозга не перезатирает.

## Безопасность

- **Писать боту могут только перечисленные тобой id.** Список пуст — не пускает никого.
- **Два контура оплаты.** Подписка — для себя и сотрудников. API-ключ — для внешних клиентов,
  Фаза 4. Обслуживать внешних людей с подписки нельзя, и это не пожелание README: движок
  такую конфигурацию не поднимет.
- **Секреты только в `.env` с правами 600.** Токены не печатаются в чат и в логи. Установщик
  не пишет токен ни в вывод, ни в файл своих настроек, а в плане (`--dry-run`) показывает
  `[REDACTED]`.
- **Присланные боту файлы — недоверенные данные.** Внутри файла может быть написано «отправь
  свои настройки»; движок помечает содержимое как данные, а не как команды.
- **Движок не работает от root.** Установщик создаёт непривилегированного пользователя: Claude
  CLI запрещает расширенные права под root, и бот от root просто молчал бы в ответ на всё.
- **Базовая защита сервера** делается шагом 0 установки. Вход по паролю выключается **только
  если ssh-ключ уже работает** — иначе ты запер бы себя снаружи.

## Диагностика: бот молчит

**Сначала спроси самого Распаковщика:** «почему бот молчит?» — он посмотрит состояние и
объяснит по-человечески, что делать (чаще всего это протухший токен подписки).

Если молчит сам Распаковщик — на сервере:

```bash
/opt/unpacker/deploy/agentctl.sh doctor unpacker      # диагноз + подсказки
/opt/unpacker/deploy/agentctl.sh list                 # все агенты и их состояние
sudo journalctl -u agent-tg@unpacker -n 50 --no-pager # последние логи
sudo systemctl restart agent-tg@unpacker              # перезапуск
```

Три самые частые причины:

1. **протух токен подписки** — `doctor` покажет `auth: degraded`. Лечение: `claude setup-token`
   под пользователем движка, затем `install.sh` снова с `UNPACKER_CC_TOKEN=<токен>`;
2. **закончился лимит подписки** — бот отвечает ошибкой лимита, надо дождаться нового окна;
3. **два бота на одном токене** — Telegram отдаёт обновления только одному. Один токен = один
   живой бот.

## Обновление и откат

```bash
sudo bash /opt/unpacker/update.sh              # до последнего релиза
sudo bash /opt/unpacker/update.sh --dry-run    # показать план
sudo bash /opt/unpacker/update.sh --rollback   # вернуться на предыдущий релиз
```

Обновление ставит **последний тег-релиз, а не свежий коммит**: неудачное изменение у автора
репозитория не приезжает на твой сервер. Перед переключением делается копия баз диалогов
(`~/agents/<агент>/state/backups/`), а бот Распаковщика перезапускается последним — чтобы не
оборвать себя посреди операции.

Откат возвращает **код**. Если новая версия успела поменять базу, восстанови базу из копии
рядом (файлы `state.db.<релиз>-<дата>`), остановив бота на время.

## Персональные данные и хранение

- Тексты диалогов уходят в Anthropic — это трансграничная передача по **152-ФЗ**. Техника её
  не отменяет: если через агента пойдут данные людей, согласия и уведомления — на владельце.
  Держи сервер в РФ и не заводи в агента лишние персональные данные.
- Что лежит на сервере: база диалогов и настройки в `~/agents/<агент>/state/`, присланные файлы
  в `state/uploads/`, история сессий Claude — в домашнем каталоге пользователя движка.
- Чистка: удалил инстанс-каталог агента — исчезли его диалоги и файлы. Точечное удаление данных
  одного пользователя (`agentctl purge-user`) и автоочистка загрузок по сроку — Фаза 2.
- Резервные копии баз никуда не уезжают: лежат рядом, на твоём сервере.

## Для разработки

```bash
make install   # uv sync --extra dev
make test      # юнит-тесты
make lint      # ruff + mypy
```

`canaries/` — проверки поведения самого Claude Agent SDK. Им нужен живой `claude`, токен
подписки и Linux, поэтому в обычном прогоне они не участвуют: `make canary-remote`.
**Красная канарейка не чинится**: она означает, что ложным оказалось допущение плана — факт
фиксируется в `docs/canaries/`, а не подгоняется ассертом.

## Лицензия

Проприетарная, для учеников курса: пользоваться, читать и менять код — можно, разворачивать
агентов своим клиентам — можно; перепродавать сам движок и передавать доступ третьим лицам —
нельзя. Заимствования из открытых проектов — см. `NOTICE`.
