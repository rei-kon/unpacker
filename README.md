# Распаковщик

Движок агентов на Claude Agent SDK: берёт «папку-мозг» (личность + знания агента) и делает
из неё живого агента на выбранной поверхности — Telegram-бот, чат на сайте, отдельный бот.

> **Статус: Фаза 0 — фундамент.** Сейчас в репо только ядро и регресс-канарейки на поведение
> SDK. Бота отсюда пока не поднять: адаптер Telegram, `deploy.sh` и мозг Распаковщика приходят
> в Фазах 1a/1b. Полный README «путь новичка» — Фаза 1b.
>
> Карта продукта — `docs/plans/2026-07-17-unpacker-deployer/PLAN.md` в рабочем репо офиса.

## Что здесь есть

| Каталог | Что |
|---|---|
| `engine/core/` | ядро: гейт доступа, сессии, сборка стрима SDK, конфиг, форматирование |
| `engine/tests/` | юнит-тесты ядра (41 тест, перенесены из пилота `sdk-bot-pilot`) |
| `canaries/` | регресс-канарейки на допущения Agent SDK — гоняются на Linux-VPS, не в CI |
| `docs/canaries/` | письменно зафиксированное поведение SDK (результаты прогонов) |

## Разработка

```bash
make install   # uv sync --extra dev
make test      # юнит-тесты ядра
make lint      # ruff + mypy
```

## Канарейки

Канарейка проверяет **чужое** поведение — Claude Agent SDK, — а не наш код. Ей нужен живой
`claude` CLI, токен подписки и Linux, поэтому в CI она не гоняется.

```bash
make canary-remote          # с мака: rsync на VPS + прогон там
make canary                 # на самой машине
```

**Красная канарейка не чинится.** Она означает, что допущение плана ложно: фиксируем факт
в `docs/canaries/` и правим план, а не подгоняем ассерт под реальность.
