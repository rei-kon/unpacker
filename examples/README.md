# examples/ — готовые мозги, чтобы попробовать

| Папка | Что это |
|---|---|
| `assistant/` | Личный рабочий ассистент. Разворачивается **без правок** — годится как первый агент после Распаковщика. |

Как развернуть: скажи Распаковщику в Telegram

```
разверни мозг /opt/unpacker/examples/assistant в телеграм
```

Путь — **полный, от корня**. Короткое `examples/assistant` не сработает: рабочая папка
Распаковщика это его собственный мозг, и относительный путь он будет искать там.

Он спросит имя агента и токен бота (нужен ОТДЕЛЬНЫЙ бот из @BotFather — один токен = один бот;
токен попросит положить в файл на сервере, а не присылать в чат), покажет план и после «да»
поднимет агента.

Свой мозг делают из `brains/_template/` — там всё прокомментировано. Копию кладут туда, где её
видит пользователь движка (по умолчанию `/home/unpacker/brains`), а не в домашнюю папку root.
